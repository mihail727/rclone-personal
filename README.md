# rclone-personal

Личный OAuth-клиент Google Drive для программы [RClone Manager](https://github.com/zarestia-dev/rclone-manager) / rclone.

**Зачем это приложение.** Приложение зарегистрировано только для личного
использования: монтирование и синхронизация моего собственного Google Drive
через rclone на принадлежащем мне компьютере.

**Какие данные доступны.** Приложение запрашивает доступ (scope
https://www.googleapis.com/auth/drive) к моему собственному диску:

- просмотр списка и содержимого файлов и папок Drive;
- чтение, запись и удаление файлов по моим действиям в rclone.

**Кому передаются данные.** Никуда. Токен авторизации хранится локально
на моём компьютере в файле конфигурации rclone. Серверов, аналитики,
логов и передачи данных разработчику или третьим лицам у приложения нет.

**Управление доступом.** Доступ можно отозвать в любой момент:
[myaccount.google.com](https://myaccount.google.com) → Безопасность →
«Приложения с доступом к аккаунту» → отозвать.
