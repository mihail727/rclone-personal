# Политика конфиденциальности

**Приложение:** RClone Manager (личный OAuth-клиент Google Drive)
**Дата обновления:** 2026-11-11
**Контакт:** suppnms@gmail.com

## 1. Какие данные обрабатывает приложение
Приложение используется исключительно как клиент rclone для доступа
к **собственному** Google Drive пользователя, который сам прошёл
авторизацию. Приложение получает доступ к:
- метаданным файлов и папок Drive (имена, размеры, дата изменения);
- содержимому файлов (чтение, запись, удаление) при выполнении
  операций монтирования, копирования и синхронизации из rclone.

## 2. Как хранятся данные
OAuth-токен приложения хранится только локально на компьютере
пользователя, в файле конфигурации rclone. Приложение не имеет
серверов, удалённого хранилища, аналитики и телеметрии.

## 3. Передача данных
Данные не продаются, не передаются и не раскрываются третьим лицам.
Все запросы выполняются напрямую между устройством пользователя
и API Google (https://www.googleapis.com).

## 4. Отзыв доступа
Пользователь может отозвать доступ в любой момент через настройки
своего аккаунта Google: https://myaccount.google.com → «Безопасность» →
«Приложения с доступом к аккаунту».

## 5. Изменения
Изменения этой политики публикуются в этом же файле.
